Control Area Detail

1. Firewalls & Boundary Protection

ACTION REQUIRED

Only the services you actually need should be reachable from the internet. Everything else should sit behind a firewall.

Open port 21/FTP HIGH ACTION REQUIRED

A file-sharing service is open to the internet. It sends usernames and passwords without scrambling them, so anyone watching the network can read them.

Fix: Replace FTP with SFTP/FTPS, disable anonymous login, and restrict access by IP/VPN.

21/ftp vsftpd 2.3.4
Open port 3306/MySQL HIGH ACTION REQUIRED

A database is open directly to the network. Databases hold the crown jewels and should not be reachable from outside.

Fix: Bind to localhost/app subnet only and enforce strong credentials.

3306/mysql MySQL 5.5.62
Open port 3389/RDP HIGH ACTION REQUIRED

The Windows 'remote screen' service is open to the internet. Attackers constantly scan for this and try to guess passwords or use known break-in bugs.

Fix: Put RDP behind a VPN, enforce MFA and lockout, and patch.

3389/ms-wbt-server Microsoft Terminal Services
Open port 22/SSH MEDIUM ADVISORY

A remote 'control panel' for the server is reachable. It is encrypted, but if the password is weak, attackers can keep guessing until they get in and take over the machine.

Fix: Require SSH keys (disable password login), enforce fail2ban/rate-limiting, and restrict source IPs.

22/ssh OpenSSH 7.4

2. Secure Configuration

ACTION REQUIRED

Systems and software should be set up securely — no default settings, weak encryption, or information leaks.

Obsolete SSL/TLS Protocol Enabled HIGH ACTION REQUIRED

The site still supports old, broken versions of its 'lock'. Attackers can use known tricks to weaken or read the encrypted traffic.

Fix: Disable SSLv2/SSLv3/TLS 1.0/1.1; allow only TLS 1.2+.

3. Security Update Management

ACTION REQUIRED

Software must be supported and patched. Known, unpatched vulnerabilities are the most common way in.

Apache 2.4.49 Path Traversal / RCE (CVE-2021-41773) CRITICAL ACTION REQUIRED

This web-server version lets attackers read files they shouldn't and can even run commands on the server.

Fix: Upgrade Apache to 2.4.51 or later.

Apache httpd 2.4.49
vsftpd 2.3.4 Backdoor (CVE-2011-2523) CRITICAL ACTION REQUIRED

This exact file-server version contains a hidden backdoor that hands attackers complete control of the machine.

Fix: Upgrade vsftpd immediately and treat the host as compromised.

vsftpd 2.3.4

4. User Access Control

ACTION REQUIRED

Accounts must use strong, unique credentials and least privilege. Weak or default logins are an open door.

Weak / Guessable Credentials HIGH ACTION REQUIRED

A login was cracked because the password was too simple or a default. In plain terms: the passwords are weak and easy to guess, so an attacker can just walk in.

Fix: Enforce a strong password policy, change all defaults, add account lockout, and enable multi-factor auth.

ssh login 'admin' with password 'Password1'

Methodology & Limitations

Findings were produced by the PHANTOM assessment framework from an external perspective (the view an attacker has of your internet-facing systems) and mapped onto the Cyber Essentials control areas. Controls marked “Verify Internally” (such as malware protection and device configuration) cannot be confirmed from outside and must be checked on the devices themselves — the PHANTOM internal controls checker can confirm these.
